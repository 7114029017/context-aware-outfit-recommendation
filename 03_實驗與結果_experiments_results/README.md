# 實驗與結果

本區依期刊與論文採納的實驗脈絡整理結果。每個實驗資料夾通常包含三種內容：

1. 實驗明細或稽核資料，例如 row-level audit、manual review sheet、per-seed summary。
2. 解釋文字或實驗報告，例如 interpretation note、training report。
3. `圖表_figures_tables/`：該實驗在論文或期刊中使用的正式表格與圖檔。
4. `source_programs/`：產生或重現該實驗結果的程式碼。

`source_map.csv` 與 `source_map.txt` 保留圖表來源追蹤資訊，用於回查每個圖表所在實驗與對應程式碼。
