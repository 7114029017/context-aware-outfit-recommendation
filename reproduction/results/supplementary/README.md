# Supplementary outputs

Supplementary analyses of the official run, generated by
`reproduction/scripts/supplementary/run_all.sh --official`; see
`reproduction/docs/supplementary_analyses.md`.

| Folder | Source | Content |
|---|---|---|
| `full_20261002T161428Z/` | Official run's saved fair-subset and main outputs | Category, context-subset, factor, term and case analyses (2025 tables T12-T17; thesis Figures 4-7 to 4-13; 2025 figures F03, F04); factor effects (2025 tables T08, T09); BH-family sensitivity; Wilcoxon tests of the main experiment (2025 table A14) |
| `input_data_audit/` | 2025 input data used by the official run | Temperature prefixes, feature identity, equation (2), split overlap, counterfactual pairs, annotation counts, CLO distribution (thesis Table D-3, Figure D-4), category threshold (thesis Section 5.2) |
| `paper_value_checks/` | Input data and preserved 2025 outputs | Manuscript Tables 1, 2, 5 (proxy values, target clues), 8 and 9 |
| `judge_audit_checks/` | Preserved judge scores and human audit | Thesis Figures 4-1, 4-3 and 4-4 (table T31); human audit scores (2025 tables T30, A41; figures F30-F32); 2025 figures F18 and F20; judge-independence scan (tables A05, A06) |
| `met_reference_check/` | Official 2024 Adult Compendium (downloaded) | The 457-entry MET reference list rebuilt with the thesis rule; thesis Table 3-1 |
| `checklist_coverage/` | Judge checklists; Nomic text embedding model (downloaded) | Thesis Figure 4-2 |
| `dataset_tables_check/` | Polyvore metadata, generated descriptions, fair subset | 2025 dataset tables T00, T01, A01, A02, A12 and A13 (471 values, all equal) |

These analyses come after the 35 training units. The formal results of the
official run are in `reproduction/results/summary/full_20261002T161428Z/`. A new
full run (`reproduce_all.sh --fresh`) writes the same analyses of its own
outputs into its folder (`<run folder>/supplementary/`, with the run analyses in
`run_analyses/`), not here.
