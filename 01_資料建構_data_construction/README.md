# 資料建構

本區保留期刊與論文採用的資料建構重點，而不是完整原始資料備份。

- `01_使用資料與資料範圍_dataset_scope/`：PO-D 主實驗資料範圍、原始文字長度與生成覆蓋率等資料特徵表。
- `clo_met_temperature/`：CLO、MET、溫度換算與對照結果。
- `generated_descriptions/01_生成結果_generation_results/`：情境感知描述生成結果。
- `generated_descriptions/02_三因子拆分_wos_factor_split/`：最後採用的天氣、場合、風格三因子拆分結果與相關摘要表。
- `llm_judge_checklists/`：三階段評分清單與 LLM-as-a-Judge 相關設定。
